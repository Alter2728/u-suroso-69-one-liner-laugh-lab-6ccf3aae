An entry for make.fun's [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) bounty ($2.50 in USDC): a program that writes one short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock.

`main.py` (Python 3, standard library only) writes a single line to `/output/entry.txt`. The line is a deadpan excuse in the vacuum's own voice: the sock was lying on the floor dressed as a dust bunny, and the vacuum was never trained to tell the difference. The output is deterministic: every run writes the same 125-character line, inside the gate's 1–200 character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
